# Coursera Auto Solver 🎓⚡

An advanced Chrome extension built to speedrun your courses efficiently — powered by modern AI.
This extension intelligently analyzes and interacts with Coursera, letting you auto-complete videos, readings, and automatically solve quizzes with high accuracy and precision.

### ✨ Features

✅ **Smart Quiz Solver:** Uses AI (like Gemini 2.5 Flash) to predict and select correct answers directly on the page.
⏩ **Media Automation:** Instantly complete time-consuming videos and reading materials with a single click.
💬 **Dialogue Auto-Fill:** Drafts the perfect responses for interactive course dialogues.
📋 **Quick Copy & Insights:** Copy quiz questions instantly or view course passing requirements.
⚡ **Seamless Integration:** Automatically detects the Coursera environment and adapts its logic to the specific page.
🎯 **Saves Time:** Completes course materials faster and more accurately than manual attempts.
🎨 **Stunning UI:** Features a gorgeous, native macOS-inspired Liquid Glass interface matched with Coursera's color palette.

### 🚀 How to Install

1. Clone or download this repo into any folder on your computer.
2. Open Google Chrome.
3. Go to: `chrome://extensions/`
4. Toggle on **Developer Mode** (top right corner).
5. Click on **"Load unpacked"**.
6. Select the folder where you saved this repo.
7. That’s it — the extension is live! 🎉

*Note: Version 1.1 includes a brand-new UI, faster execution, and robust API provider selection.*

### ⚡ How to Use

1. Click the **Auto Solver** icon in your Chrome toolbar.
2. Click the **AI Provider** dropdown to select your preferred model (e.g., Gemini 2.5 Flash), and paste your API Key.
3. Visit any supported course module on Coursera:
   * A Quiz or Assessment
   * A Video or Reading item
4. Click **“Solve Current Quiz”** or **"Complete Materials"** in the popup.
5. Sit back and let the magic happen!
